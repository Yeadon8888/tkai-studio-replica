# 本地确认台

人工处理确认节点时，优先启动本地确认台：

```bash
python3 kit/studio.py console
```

浏览器打开 `http://127.0.0.1:8765`。服务固定监听回环地址，不接受局域网或公网连接；端口可用 `--port` 修改。

## 页面内容

- 首页列出各品的数据推导阶段、已花与预算上限、待确认数量。读取状态时会幂等补建当前阻塞的确认节点，不会执行模型或付费步骤；会阻塞后续付费步骤的对标、脚本、预算节点排在前面。
- 对标节点显示已登记的链接、播放数据、档位与理由，可把选择和档位写进决定说明。
- 脚本节点逐段显示画面提示词、口播、字幕、时长和口播词数。保存修改时后端重新运行同一套脚本校验；失败时逐条显示，原文件不被覆盖。
- 预算节点按生成单元显示 `models.select` 的模型、选择理由、时长、单价、合计和品剩余预算。
- 成片判定把成片与对标并排显示，标题显示成片总时长与视频费用，判定区显示闸门判定和最新评审时间，旧评审列为历史。无证据低分按专家名称与中文维度列出；旧记录只有专家序号时按 `experts.yaml` 顺序映射。专家问题的时间码可跳转成片。可选“可用 / 返修 / 放弃”，后两项必须说明原因。
- 对标播放按本地副本、仍可访问的远程播放地址、封面依次回退。播放地址失效时显示 `covers/<aweme_id>.jpg`、原链接和 `covers.py --refresh` 的人工刷新提示；确认台不会调用 TikHub 刷新。
- 发布节点记录是否发布、账号和链接。字段随决定说明进入原确认节点审计日志，不会自动发布。
- 统计区显示 `calibrate.py` 的专家与人工一致率，以及人工判定可用条数除以账本花费的每元产出。

## 接口边界

页面只通过 JSON 接口读写：`GET /api/status`、`GET /api/pending`、`GET /api/checkpoint/<id>`、`POST /api/checkpoint/<id>/resolve`、`POST /api/checkpoint/<id>/edit-script`。确认写入直接调用 `checkpoints.resolve`，不维护第二套状态。

`/media/` 只读提供 `STUDIO_HOME/products` 下的文件，`/research-media/` 只读提供 `STUDIO_HOME/research` 下的本地对标媒体；两者都校验解析后的真实路径并限制媒体后缀，以拒绝目录穿越。服务支持视频 Range 请求，供浏览器拖动播放进度。
