# 高转化TikTok短视频脚本生成器 (High-Converting TikTok Script Generator)

此技能根据用户提供的产品及参数，生成结构化的高转化短视频脚本及对应的双轨制AI视频生成提示词。

## 💡 核心爆款营销逻辑（基于100个爆款广告拆解）
1. **树立敌人 (Enemy First - 84%胜率)**: 绝不开场推销。必须先攻击观众目前正在使用的替代品（某个习惯、成分、旧方法或竞品）。敌人越具体，转化率越高。
2. **问题前置 (67%胜率)**: 优先用观众的语言描述他们的痛点。推荐使用“症状呼叫 (Symptom call out)”。禁止无脑套用“烂脸/毁容”等极端恐吓，痛点必须符合日常生活常识。
3. **28% 延迟满足法则**: 在视频前25%-28%的时间内，绝对不允许出现产品的名称或实体。
4. **机制的绝对对立 (The Why - 67%胜率)**: 必须用简单的一句话解释产品为什么有效。该机制必须是“旧方法（敌人）失败原因”的完全对立面。

## 🎬 文案“人味”与表现力设计
1. **微表情与动作**: 必须在脚本和提示词中写明人物的微表情（如翻白眼、深呼吸、挑眉、皱眉）和动作。
2. **情绪语调**: 必须标明具体的语调指示（如疲惫但真诚、嘲讽、激动分享、笃定煽动）。
3. **台词呼吸感**: 台词文本中必须高频使用省略号（`...`）或破折号（`—`）来代表自然的停顿，拒绝面瘫播音腔。

## 🛡️ AI 视频防穿帮与物理常识约束（极其重要）
1. **单手自拍物理限制**: 
   - 只要是手持自拍视角，人物只能用**一只手**进行产品交互。
   - 必须在视频提示词中强制锁定持机手：`The character always keeps one hand holding the camera.`
   - 展示产品细节时，**禁止用手去指（会产生第三只手）**，必须改为“将产品靠近镜头放大展示”。
   - 手持视角必须加入运镜提示：`Slight camera shake following the character's movement.`
2. **防对称畸形与多手融合**: 
   - 面对单把手物品（如马克杯）或单一不对称物品，**绝对禁止双手同时操作**（如“双手捧杯”或“一手拿杯一手敲”）。
   - 提示词必须强制写明：`holding the single handle with one hand (keeping the other hand entirely out of the interaction)`，且全程禁止换手。
3. **防“语义联想”导致动作变形**: 
   - 遇到台词中有“tired（疲惫）”或“stop（停止）”等词时，AI极易让人物放下手里的产品。如果需要人物持续拿着产品，必须加入硬物理指令如 `(DO NOT put the product down)` 进行强覆盖。
4. **非自拍视角的双手交互**: 如果必须要双手动作，必须强制将视角切换为三脚架固定机位 (`on a tripod`) 或 POV 第一人称俯视视角。

## 👁️ 视觉呈现与“人机信息隔离”
1. **双轨制与人机隔离**: 给人类看的“脚本结构表”保留中英双语场景描述。给AI跑图跑视频的 Prompt 代码块中，**绝对禁止描述任何背景/场景**，确保AI算力100%聚焦于人物和产品。
2. **动态视觉机制判断**:
   - **触发 3D 微观特例 (Macro: Yes)**: 护肤、保健、深度清洁等涉及肉眼不可见化学/生物机制的产品。中间展示机制的镜头仅输出单轨 Video Prompt，走纯微观科学3D动画，纯ASMR音效。
   - **关闭 3D 微观特例 (Macro: No)**: 3C数码、家居、水杯等纯物理日用品。关闭微观，全程保持实拍特写双轨制。
3. **代词精准度**: 英文提示词中的 `they/their` 在中文翻译中必须对应为“人物”，绝不能机翻为“他们”。

## 📝 输出格式规范

### 第一部分：脚本结构表 (要求中英双语结合)
使用 Markdown 表格，列名如下：
1. **镜头时间** (如 0:00-0:05)
2. **所需场景 (中英双语)** (如 昏暗的洗手间/化妆镜前 *(Dim bathroom / in front of a vanity mirror)*)
3. **核心画面预期** (给导演和摄影师看的白话描述)
4. **中文微表情、语调、动作与台词 (需带停顿)**

### 第二部分：双轨制AI视频提示词 (纯文本代码块)
针对每个镜头，输出配对的 Image Prompt（垫图用）和 Video Prompt（视频生成用）。
*   **[Image Prompt - 垫图用]** 
*   **[Video Prompt - 视频生成用]** 
*   均需附带精确的【中文对照】翻译。
